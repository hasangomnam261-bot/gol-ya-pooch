پروژه اندروید مسابقات گل یا پوچ - رایة‌الهدی

این بسته فایل APK آماده نصب نیست. پروژه برای ساخت در Android Studio تهیه شده است.

روش ساخت APK:
۱. پوشه GolYaPooch-AndroidStudio را با Android Studio باز کنید.
۲. Android SDK 35 و Android Gradle Plugin 8.7.3 (به‌همراه Gradle سازگار) را نصب یا از اینترنت دریافت کنید.
۳. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
۴. در app/build/outputs/apk/debug فایل app-debug.apk ساخته می‌شود.

برنامه دو بخش مدیر و داور دارد. مدیر برای هر داور فایل مأموریت JSON تولید می‌کند.
داور فایل را وارد و نتایج را ثبت می‌کند و فایل گزارش JSON به مدیر می‌دهد.
مدیر هنگام ورود گزارش، تنها نتایج معتبر فاقد تداخل را با تأیید خود اعمال می‌کند.
انتقال‌ها آفلاین و با فایل است، نه همگام‌سازی اینترنتی فوری.

تذکر: چون تبادل فایل آفلاین فاقد امضای رمزنگاری‌شده است، فایل گزارش جعل‌ناپذیر نیست.
برای مسابقات رسمی، گزارش را با داور تطبیق دهید.
