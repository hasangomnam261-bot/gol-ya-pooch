ساخت APK فقط با گوشی اندرویدی (بدون لپ‌تاپ)

این پروژه به GitHub Actions مجهز شده است تا ساخت APK روی سرورهای GitHub انجام شود.

مراحل:
۱) در مرورگر گوشی وارد github.com شوید و حساب رایگان بسازید یا وارد شوید.
۲) از علامت + گزینه New repository را بزنید. نام دلخواه (مثلاً gol-ya-pooch) بدهید و Repository را Private یا Public انتخاب کنید.
۳) فایل ZIP پروژه را در گوشی استخراج کنید. سپس در مخزن GitHub گزینه Add file > Upload files را بزنید و تمام محتویات پوشه GolYaPooch-AndroidStudio را (از جمله پوشه مخفی .github) بارگذاری و Commit کنید.
   نکته: اگر آپلود پوشه .github با مرورگر دشوار بود، فایل .github/workflows/build-apk.yml را در سایت GitHub با مسیر دقیق بسازید.
۴) در مخزن، زبانه Actions را باز کنید. گردش‌کار Build GolYaPooch APK را انتخاب و Run workflow را بزنید.
۵) پس از پایان موفق (علامت سبز)، وارد اجرای انجام‌شده شوید و از بخش Artifacts فایل GolYaPooch-debug-apk را دانلود کنید.
۶) ZIP دانلودشده را استخراج و app-debug.apk را نصب کنید. ممکن است اندروید اجازه نصب از این منبع را بخواهد.

نکته‌ها:
- ساخت APK در فضای ابری GitHub انجام می‌شود؛ لازم نیست Android Studio روی گوشی نصب شود.
- برای دریافت Artifact باید وارد همان حساب GitHub باشید.
- این APK نسخه Debug است، نه نسخه انتشار امضاشده برای فروشگاه.
- فایل‌ها و نتایج مسابقه روی خود برنامه و در حافظه دستگاه می‌مانند؛ همگام‌سازی آنلاین خودکار وجود ندارد.
